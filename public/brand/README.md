# Brand assets

Place the official OSSF logo files here when supplied:

- `ossf-logo.svg` (preferred) or `ossf-logo.png` — the logo mark or horizontal
  lockup on a **transparent** background, legible on the dark navy header/footer.

Then set `OFFICIAL_LOGO` in `components/ui/Logo.tsx`. See the "Logo" section of
the project README for the full list of logo-dependent files (favicon, Apple
icon, social share image).
